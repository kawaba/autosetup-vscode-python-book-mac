# Portable Python + VS Code 環境セットアップ (Mac版)

ダウンロードして実行するだけで、Python 3.13 と VS Code（日本語化済み）が
このフォルダの中だけに独立してセットアップされます。他のソフトを事前に
インストールしておく必要はありません。管理者権限も必要ないので、学校のMacなどでも使えます。

## 動作環境

- macOS（Apple Silicon / Intel どちらも対応）
- インターネット接続（セットアップ時のみ必要）

## 1. ダウンロード

このページ上部の **Code** ボタン → **Download ZIP** をクリックしてダウンロードし、
好きな場所（デスクトップなど）に展開（解凍）してください。

## 2. セットアップ

展開したフォルダの中にある `setup.command` を**ダブルクリック**して実行してください。
ターミナルが自動で開いて、そのままセットアップが始まります（コマンドの入力は不要です）。

### 「開けません」という警告が出たとき

インターネットからダウンロードしたファイルなので、初回は macOS の保護機能（Gatekeeper）によって
「“setup.command”は開いていません」「開発元を確認できないため開けません」などの警告が出て、
開けないことがあります。次の方法1か方法2で開いてください。

**方法1：システム設定から許可する**

1. 警告のダイアログで「完了」（または「キャンセル」）を押して閉じます。
   ※「ゴミ箱に入れる」は押さないでください。
2. アップルメニュー →「システム設定」→「プライバシーとセキュリティ」を開きます。
3. 下の方にある「セキュリティ」の欄に、“setup.command”がブロックされたという表示と
   「このまま開く」ボタンがあるので、押します。
4. もう一度確認のダイアログが出るので「このまま開く」を押します（パスワードを聞かれたら入力します）。

※ macOS 14 Sonoma 以前では、`setup.command` を右クリック（またはControl+クリック）→「開く」でも開けます。
macOS 15 Sequoia 以降では、この方法は使えなくなりました。

**方法2：ターミナルで印を外す**

方法1で開けない場合（学校の Mac などで許可できない場合）は、ダウンロードしたファイルに付いている
「インターネットから取得した」印を、ターミナルで外します。

1. 「アプリケーション」→「ユーティリティ」→「ターミナル」を開きます。
2. `xattr -dr com.apple.quarantine ` と入力します（最後に半角スペースを1つ入れます）。
3. 展開した `portable-python-vscode` フォルダを、ターミナルのウィンドウにドラッグ＆ドロップします。
   フォルダの場所が自動で入力されます。
4. Enterキーを押します。何も表示されなければ成功です。
5. もう一度 `setup.command` をダブルクリックします。

### セットアップ中のこと

- Python本体のダウンロードや、多数のPythonライブラリ（numpy, pandas, jupyter など）、
  VS Code本体のダウンロード・拡張機能のインストールを自動で行うため、
  **完了まで5〜10分ほど**かかります。
- 途中で入力を求められることはありません。終わるまでそのまま待ってください。
- 途中でエラーが起きた場合は「エラーが発生したため、セットアップを中止しました」と表示されて止まります。
  その上に表示されているメッセージを確認してください。
- セットアップが完了すると、`config` フォルダなど不要になった作業用ファイルは
  自動で削除されます（消えていて正常です）。

## 3. 起動方法

セットアップが終わると、画面の下の **Dock** に **VS Code Python** のアイコンが置かれます。
これをクリックすると、`workspace` フォルダを開いた状態で VS Code が起動します。
ターミナルのウィンドウは開きません。

- セットアップの途中で、Dock が一瞬消えて、また表示されます。アイコンを置くためで、故障ではありません。
- Dock にアイコンが無いときは、フォルダの中の **`VS Code Python.app`** をダブルクリックしてください。
  Dock にドラッグして置くこともできます。
- `VS Code Python.app` は、セットアップの最後にこの Mac の上で作られます。
  ダウンロードしたものではないので、「開けません」という警告は出ません。
- `VS Code Python.app` をフォルダの外（アプリケーションフォルダなど）へ移動すると、起動できなくなります。
  アプリケーションフォルダに置きたいときは、右クリック →「エイリアスを作成」で作ったエイリアスを置いてください。
- `VS Code Python.app` が無い場合（作成に失敗した場合）は、`launch-vscode.command` を
  ダブルクリックしても起動できます。この場合はターミナルのウィンドウが開きますが、
  VS Code の起動後に閉じてかまいません（閉じても VS Code は終了しません）。
- `portable-python-vscode` フォルダを移動すると、Dock のアイコンは使えなくなります。
  アイコンを Dock の外へドラッグして消し、新しい場所の `VS Code Python.app` を Dock に置き直してください。

### ⚠️ VS Code を終了するときは Cmd + Q を押してください

Mac では、ウィンドウ左上の赤い ✕ ボタンを押してもウィンドウが閉じるだけで、VS Code は終了しません。
終了するときは **Cmd + Q** キーを押してください。

メニューなどが英語表示のときは、Cmd + Q で終了してから、もう一度起動してください。

3. 使い方は、Windows版（autosetup-vscode-python-book）を参照してください。
   GitHub Copilotの設定ガイドもWinodws版に掲載されています。

## インストールされるもの

- **Python 3.13**（自己完結型のスタンドアロンビルド。このフォルダの外の環境には
  依存しないので、フォルダごと他のMacに持って行っても動作します）
- 主なライブラリ: numpy, pandas, matplotlib, jupyterlab, pygame, arcade,
  flask, fastapi, scikit-learn など（詳しくは `setup.command` を参照）
- **VS Code**（ポータブル版・日本語化済み）
- VS Code拡張機能: Python, Pylance, Jupyter, Black Formatter, GitHub Copilot,
  Markdown関連 など
- **HackGen フォント**（SPD の表示用。`~/Library/Fonts` にインストールされます）<br>
  SPD の罫線（`─` `│` `├` `└` `┬`）を日本語と同じ全角幅で表示して、縦罫線の位置をそろえるために使います。
  Mac に最初から入っている等幅フォント（Menlo など）は罫線が半角幅なので、縦罫線がずれてしまいます。
  このフォントだけは、このフォルダの外（自分のユーザーのフォントフォルダ）に入ります。
  管理者権限は必要ありません。

## トラブルシューティング

- **「開けません」という警告が出て `setup.command` を開けない**: 「2. セットアップ」の
  「「開けません」という警告が出たとき」を参照してください。
- **SPD の縦罫線がずれる**: HackGen フォントが入っていない可能性があります。
  - 「Font Book」アプリで「HackGen」を検索して、インストールされているか確認してください。
  - 入っていない場合は、もう一度 `setup.command` を実行してください（インストール済みのものはスキップされます）。
    セットアップ中に「警告: HackGen フォントをインストールできませんでした」と出た場合は、ネットワークを確認してください。
  - 手動で入れる場合は、[HackGen のリリースページ](https://github.com/yuru7/HackGen/releases) から
    `HackGen_v2.10.0.zip` をダウンロードして展開し、`HackGen-Regular.ttf` と `HackGen-Bold.ttf` を
    ダブルクリックして「インストール」を押してください（`HackGenConsole` の方は罫線が半角幅なので使いません）。
  - フォントを入れた後は、VS Code を **Cmd + Q** で終了してから起動し直してください。
  - 2026-10-04 より前にセットアップした環境では、VS Code の設定にフォントの指定がありません。
    VS Code で **Cmd + ,** を押して設定を開き、「Font Family」を検索して、
    「Editor: Font Family」を `HackGen, 'Osaka-Mono', Menlo, monospace` に変更してください。
- **フォルダを別の場所に移動した**: 移動後、もう一度 `setup.command` を実行してください
  （ダウンロード済みのPythonやVS Codeは再利用され、設定ファイルのパスだけが
  新しい場所に合わせて更新されます）。
- **拡張機能が正しく動かない/日本語にならない**: 一度 `vscode` フォルダと
  `python` フォルダを削除してから、`setup.command` を実行し直してください。
